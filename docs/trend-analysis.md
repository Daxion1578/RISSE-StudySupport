# 情報処理安全確保支援士試験 出題傾向分析（ロードマップの根拠）

最終更新: 2026-08-17
このドキュメントは、アプリのロードマップ生成ロジック（単元の重要度ランク S/A/B）の根拠。
傾向を更新するときは、まずこのファイルを更新し、その内容を `index.html` の UNITS の trend 値に反映する。

## 1. 試験制度の現状（2026年度〜）

2026年度（令和8年度）から試験制度が大きく変わっている。

- **CBT方式へ移行**（試験会場のパソコンで受験）
- 従来の「春期（4月）／秋期（10月）」から**「前期／後期」**へ変更
- 科目名変更: 午前I → 科目A-1、午前II → 科目A-2、午後 → 科目B
- 2026年度の出題範囲自体は変更なし。2027年度以降に科目Aの出題体系再編（テクノロジ／マネジメント／ストラテジ → ビジネス・テクノロジ・セキュリティ・倫理）の方向性が示されている

**確認済みの試験日程（2027年に受験できる回 = 後期試験）**

| 項目 | 日程 |
|---|---|
| 申込受付 | 2027年1月27日〜2月27日 |
| 科目A-1・A-2試験 | 2027年2月20日〜3月2日 |
| 科目B試験 | 2027年3月16日〜3月28日 |
| 合格発表 | 2027年6月頃 |

※前期試験は2026年11月頃実施予定。アプリの既定目標は後期試験（科目B開始日 2027-03-16 を逆算基準）とする。

## 2. 科目A-2（旧午前II）の傾向

- 25問中、**情報セキュリティ分野が約17問、ネットワーク分野が約3問**、残りがDB・開発・サービスマネジメント・監査など
- **過去問からの再出題率が高い（約4〜5割）**。特に3〜8回前の問題が再出題されやすく、過去10回分の演習が定番対策
- 頻出トピック（直近の実例: DRDoS、SAML認証、OAuth 2.0、暗号化、マルウェア、ISMAP、サイバーセキュリティフレームワーク、証拠保全、スパニングツリー、HTTPメソッド、SQL、静的コード解析など）

→ ロードマップへの反映: 「科目A過去問演習」を独立単元として2回分＋4回分の2段階で確保。暗号・認証・攻撃手法・NWプロトコルの基礎単元を高ランクに。

## 3. 科目B（旧午後）の出題テーマ実績

過去問サイト（情報処理安全確保支援士ドットコム）で確認した直近3回の全テーマ:

| 実施回 | 問1 | 問2 | 問3 | 問4 |
|---|---|---|---|---|
| 令和6年秋 | インシデントレスポンス | ドメイン名変更（DNS・メール） | クレジットカード情報の漏えい（Web） | セキュリティ診断 |
| 令和7年春 | サプライチェーンのリスク対策 | 脆弱性管理 | スマートフォン向けアプリ開発 | IT資産管理及び脆弱性管理 |
| 令和7年秋 | コンサル業務で利用するSaaS | 暗号資産交換業のセキュリティ | 情報システムのセキュリティ強化 | 製造業におけるセキュリティ管理 |

一般的傾向（対策情報サイトの分析より）:

- 1つの設問に開発・インフラ・ネットワークなど**複数要素が混じる融合問題**が年々増加
- **新技術は台頭から2〜3年で出題**される（クラウド、ゼロトラスト、暗号資産など）

## 4. 傾向から導いた重要度ランク

- **Sランク（最重点。直近で繰り返し出題 or 科目Bの定番題材）**
  - 脆弱性管理・IT資産管理（令和7年春に2問）
  - クラウド・SaaSのセキュリティ、サプライチェーン・委託先管理
  - インシデント対応、マルウェア・ランサムウェア
  - Webアプリセキュリティ（XSS・SQLi・CSRF・セッション管理）、セキュアプログラミング
  - 認証連携（SAML/OAuth/OIDC）、暗号基礎・PKI・TLS
  - DNS・メールセキュリティ（SPF/DKIM/DMARC）
  - 科目A・B過去問演習
- **Aランク（頻出。確実に得点源にする）**
  - FW/IDS/IPS/WAF、VPN・ゼロトラスト、監視・SIEM
  - 標的型攻撃、盗聴・中間者攻撃、多要素認証・FIDO
  - リスクアセスメント、ISMS、フォレンジックス、OT/IoT、法規・ガイドライン
- **Bランク（基礎教養・出題は相対的に少ない）**
  - OS基礎、無線LAN、DoS/DDoS、物理セキュリティ、支援士制度、周辺法規

## 5. 収録250問の実測分布に基づく更新（2026-08 レビュー反映）

直近5年・10回分（250問）を収録した結果、実際の出題数と重要度ランクに乖離が見つかったため更新する。

- **b5「暗号技術の応用と危殆化」を B → S に変更（目安時間 3h → 5h）**: 収録250問中13問（全単元2位）。CRYPTREC暗号リスト・耐量子暗号(PQC)・量子暗号・FIPS 140-3・サイドチャネルが繰り返し出題されている
- 合格判定レビュー（IPA公式シラバス照合）に基づき、シラバス記載だが未収録だった用語を教材に追補: STRIDE/ATA、プロンプトインジェクション、ディープフェイク、ファジング、セキュア/プライバシーバイデザイン、ハーデニング、コンテナ/Kubernetes、IEC 62443/CSMS、OSINT、NISC/ISAC/J-CRAT、LPWA
- 科目Bは頻出テーマ網羅のため令和6年秋・令和7年春の全8問を追加収録（テーマ実績は上表参照）
- ロードマップは科目A試験日（2/20）を中間締切として扱い、科目A対策単元をその2週間前までに完了させる配分に変更
