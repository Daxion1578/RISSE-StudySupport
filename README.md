# RISSE-StudySupport — 支援士合格ロードマップ

情報処理安全確保支援士（登録セキスペ）合格のための学習支援Webアプリ。
サーバー不要の単一HTMLファイルで動き、学習データはブラウザ内（localStorage）に保存されます。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK。GitHub Pagesでの公開も可能）
2. **レベル診断**（オリジナル25問）を受ける → 分野別の正答率と弱点がわかる
3. **ロードマップ**タブで、目標試験日から逆算した週次の学習計画を確認する
4. 学習した単元にチェックを入れる → 自動で学習記録に残る

## 主な機能

| タブ | 内容 |
|---|---|
| ホーム | 残り日数・進捗・今週やる単元・未消化（遅れ）の警告 |
| レベル診断 | 5分野×5問。結果で弱点分野の学習時間を自動増量（×1.25） |
| ロードマップ | 全54単元を試験日までの週に自動割当て。フェーズ制（基礎→暗号認証→攻撃防御→運用管理→法規→演習） |
| 単元マップ | 全単元のカバレッジ一覧。ここが全部「済」になれば学習漏れゼロ |
| 学習記録 | 何をいつ勉強したかの自動ログ |
| 出題傾向 | ロードマップの根拠となる出題実績・制度変更の分析 |
| 設定 | 目標試験日・週あたり学習時間・クラウド同期（GitHub Gist）・データのエクスポート/インポート |

## 設計方針

- **漏れゼロ原則**: ロードマップは全単元を必ずどこかの週に割り当てる。時間が足りなくても単元は削らず、警告を出す。予定週を過ぎて未完了の単元は「未消化」として消えずに表示され続ける
- **実態に合わせた配分**: 単元の重要度（S/A/B）は直近の出題実績の分析に基づく → 根拠は [docs/trend-analysis.md](docs/trend-analysis.md)
- **診断問題はオリジナル**: 過去問の転載はしない（著作権のため）。過去問演習は公式・過去問サイトを使う前提で、ロードマップに演習時間として組み込み済み

## PCとスマホの併用（クラウド同期）

設定タブの「クラウド同期」で、GitHubの非公開Gistを介してPC・スマホ間の学習データを共有できる。
初回のみGitHubでPersonal Access Token（classic、**gistスコープのみ**）を作成し、各端末に貼り付ける。
以後はアプリを開くたびに自動同期（衝突は単元ごとに新しい操作が勝つ）。トークンは端末のブラウザ内にのみ保存され、エクスポートファイルには含まれない。

## 既知の制限

- 同期未設定の場合、学習データはブラウザごとに独立 → クラウド同期を設定するか、エクスポート/インポートで移すこと
- 試験日程は2026年8月時点の公表情報（CBT移行後の後期試験: 科目A 2027/2/20〜、科目B 2027/3/16〜）。正式日程は [IPA公式サイト](https://www.ipa.go.jp/shiken/) で必ず確認すること
