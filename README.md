# RISSE-StudySupport — 支援士合格ロードマップ

情報処理安全確保支援士（登録セキスペ）合格のための学習支援Webアプリ。
このサイトだけで「教材を読む → ドリルで演習 → 記述対策 → 進捗管理」の学習サイクルが完結します。
素のHTML/CSS/JSの静的サイト（ビルド不要）。学習データはブラウザ内に保存され、GitHub Gistで端末間同期できます。

## 使い方

- 公開URL: `https://daxion1578.github.io/RISSE-StudySupport/`（GitHub Pages）
- またはリポジトリを取得して `index.html` をブラウザで開く（サーバー不要）

初回は①レベル診断を受ける → ②設定タブでクラウド同期を設定（推奨）→ ③ロードマップに沿って学習、の順。

## 機能

| タブ | 内容 |
|---|---|
| ホーム | 残り日数・進捗・ドリル正答率・今週やる単元・未消化の警告 |
| レベル診断 | オリジナル25問で分野別の弱点を測定。ロードマップの時間配分に反映 |
| ロードマップ | 全54単元を試験日まで週次に自動割当て（漏れゼロ保証・弱点は増量） |
| ドリル | IPA過去問（科目A-2/旧午前II）の一問一答。弱点分野優先出題・解説付き・履歴同期 |
| 教材 | 単元別テキスト＋SVG図解＋重要用語。ドリル解説からリンク |
| 科目B演習 | 過去問の長文＋記述入力＋IPA解答例比較＋採点プロンプトのコピー（AI採点用） |
| 単元マップ | 全単元のカバレッジ一覧（ここが全部「済」なら学習漏れゼロ） |
| 学習記録 | 単元完了・ドリル・演習・診断の自動ログ |
| 出題傾向 | ロードマップの根拠となる出題実績・制度変更の分析 |
| 設定 | 目標試験日・週あたり時間・クラウド同期・エクスポート/インポート |

## ファイル構成

```
index.html        画面骨格とscript読み込み
css/app.css       テーマ
js/               機能別のスクリプト（app/state/roadmap/drill/materials/exam-b）
data/units.js     単元マスタ
data/questions-a/ 科目A-2過去問データ（出典明記）
data/questions-b/ 科目B過去問データ（出典明記）
data/materials/   単元別教材（自作）
tools/            過去問追加用の半自動変換ツール（Python）
docs/             出題傾向分析
```

## 過去問データを追加するには

`tools/pdf2json.py` のコメントに手順を記載。IPA公式PDFからテキスト抽出 → AIに既存形式へ整形依頼 → `data/questions-a/` に配置 → `index.html` にscriptタグ1行追加。

## 出典・著作権

- 過去問はIPA（独立行政法人情報処理推進機構）公表の試験問題・解答例を、[IPA利用規約](https://www.jitec.ipa.go.jp/_termofuse.html)に従い出典明記の上で利用しています。各問題に出典を表示しています
- 解説・教材・図解・レベル診断の問題はすべて本プロジェクトのオリジナルです

## 既知の制限

- 学習データはブラウザ内保存。クラウド同期（設定タブ）を設定しない場合、端末間で引き継がれません
- 科目Bの採点は「採点プロンプトをAI（Claude等）に貼り付ける方式」が基本。設定タブでClaude APIキー（従量課金・ブラウザ内にのみ保存）を登録するとワンタップの自動採点も使えます
- 試験日程は2026年8月時点の公表情報。正式日程は[IPA公式](https://www.ipa.go.jp/shiken/)で必ず確認してください
